Drop your CV here, then set links.cv in assets/js/config.js to its path.

Example:
  1. Save the file as  assets/files/rafit-hasan-rion-cv.pdf
  2. In config.js:      cv: 'assets/files/rafit-hasan-rion-cv.pdf'

The "Download CV" button in the hero becomes a real download link as soon as
that path points to an existing file. Until then the button is shown disabled
instead of leading to a broken link.
